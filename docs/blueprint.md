# **App Name**: FinLit Classroom

## Core Features:

- Student Dashboard: Display student's points, class ranking, and a summary of virtual assets.
- Reward Store: A virtual storefront where students can browse available rewards and redeem them using their points.
- Virtual Stock Market: Simulated stock trading platform for students to buy/sell stocks, manage a portfolio, and learn about financial markets.
- Teacher Dashboard: Admin interface for teachers to award points to students and manage reward items.
- Interest Rate Simulator: Automatically calculate and apply interest on student balances at consistent intervals.
- AI Reward Suggestion Tool: Suggest suitable reward items, tailored to the student’s accumulated points and the recent performance in the virtual stock market.

## Style Guidelines:

- Primary color: Vibrant teal (#20A496) to foster a lively and engaging environment.
- Background color: Light teal (#E0F8F5) for a soft, unobtrusive backdrop.
- Accent color: Energetic orange (#F29422) for calls to action and highlights.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern look; suitable for both headlines and body text.
- Use cheerful, educational icons representing points, rewards, and investment activities.
- Layout features a clean, card-based design with intuitive navigation for both students and teachers.
- Implement smooth transitions and feedback animations to enhance user engagement and make the app more interactive.
